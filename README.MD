# Snakemania

Snakemania is a colorful snake game built with Python's `turtle` module. It uses a larger playfield, bright neon colors, and an on-screen score display.

## Features

- Bright neon-style color theme
- Larger game window and playfield
- Score display outside the grid
- Simple arrow-key controls

## How to Run

1. Make sure Python is installed.
2. Install the required package if needed:
   ```bash
   pip install freegames
   ```
3. Run the game:
   ```bash
   python main.py
   ```

## Controls

- Up Arrow: move up
- Down Arrow: move down
- Left Arrow: move left
- Right Arrow: move right

## Objective

Eat the food, grow longer, and avoid crashing into the walls or yourself.
